# 凯尔特结仿真 (拓扑遍历模式)

此模块实现了一个拓扑凯尔特结生成器，将参考网格对象的边转换为连续的、编织的环圈。

## 1. 架构模式: 参考对象 (Reference Object)

仿真利用 **拓扑-到-结 (Topology-to-Knot)** 的转换：

- **参考对象 (`obj_ref`)**: 一个网格（通常是细分的平面或流形体积）。其拓扑结构定义了结的结构。
- **生成对象 (`obj_gen`)**: 由 Taichi 管理的网格。它包含提取和编织后的环圈的顶点和边。

## 2. 技术规格

### 环圈遍历逻辑
插件的核心是一个具有流形意识的遍历算法 (`traverse_knot`)：
1. **连通性**: 使用 `bmesh` API 在 `face.loops` 中导航。
2. **寻路**: 对于每个未访问的环圈，它遵循 `link_loops`（跨越边的相邻面环圈）来追踪连续的循环。
3. **环圈提取**: 将这些循环提取为独立的样条线，确保参考网格的每条边都是结路径的一部分。

### 编织机制 (Weaving Mechanism)
“上下交替”模式使用 Taichi 核 (`compute_knot_points`) 并行计算：
- **锚点**: 在参考网格边的 **中点** 生成点。
- **法线计算**: 对于每个点，脚本从共享该边的两个相邻面计算组合法线。
- **相位偏移**:
    - **正向相位**: 沿法线偏移 `weave_up`。
    - **反向相位**: 沿法线偏移 `weave_down`（通常为负值）。
- **结果**: 这创造了特征性的交错外观，线程在跨越相邻段时交替处于上方和下方。

## 3. 视觉与几何节点

插件在 **生成对象** 上以编程方式生成名为 `CelticKnot_Viz` 的几何节点组：

- **贝塞尔插值**: 生成的网格边转换为具有 **自动句柄** 的贝塞尔曲线，为离散点提供平滑、流畅的曲线。
- **曲线扫掠 (Curve Sweeping)**: 使用 `Curve to Mesh` 节点和 `Curve Circle` 轮廓创建 3D 管状结构。
- **动态样式**: 倒角半径和分辨率在 Taichi 面板中公开并实时更新。

## 4. 数据接口

**生成对象** 暴露以下属性，供高级着色和几何节点效果使用：

| 属性 | 域 (Domain) | 类型 | 描述 |
| :--- | :--- | :--- | :--- |
| `weave_phase` | 点 (Point) | `FLOAT` | 归一化相位（0.0 或 1.0），指示该段处于“上”还是“下”位置。 |
| `loop_id` | 点 (Point) | `INT` | 每个连续环圈的离散索引。用户可以在几何节点中通过除以总环圈数来归一化此值，用于颜色随机化。 |

## 5. 实时同步

- **高性能更新**: 使用 `foreach_set` 在 Taichi ndarrays 和 Blender 网格数据之间进行快速同步。
- **编辑模式支持**: 包含 **外科手术式 BMesh 路径 (Surgical BMesh Path)**，允许用户在主动变形或编辑参考网格时实时更新结。
- **依赖图 (Depsgraph)**: 监控参考对象的拓扑或变换更改，以触发重新遍历和重新计算。

## 6. 默认参考对象

如果未分配参考对象，单击 **"Initialize Celtic Knot"** 将创建：
- **几何体**: 一个 4x4 的细分网格（平面）。
- **尺寸**: 1.0 单位。
- **命名**: `Celtic_Ref`。

## 7. UI/UX 工作流

1. **设置**: 选择或创建一个 **参考对象**。细分后的几何体（如网格或重新网格化后的球体）效果最佳。
2. **初始化**: 单击 **"Initialize Celtic Knot"** 生成结。
3. **调整编织**: 修改 `Weave Up` 和 `Weave Down` 以控制交错的深度。
4. **完善视觉效果**: 调整 `Bevel Radius` 以改变厚度。
5. **交互式编辑**: 移动或缩放参考对象，或进入编辑模式雕刻底层拓扑 —— 结将跟随表面并立即更新其编织模式。
