# Voronoi 实验室 (参考对象模式)

此模块实现了一个实时 2D Voronoi 生成器，将参考网格对象的顶点转换为具有贝塞尔平滑边缘的可定制 Voronoi 单元。

## 1. 架构模式: 参考对象 (Reference Object)

仿真基于 **种子-到-单元 (Seeds-to-Cells)** 的关系运行：

- **参考对象 (`obj_ref`)**: 限制在 XY 平面上的网格。其顶点充当 Voronoi 图的 2D 种子。支持编辑模式下的实时交互。
- **生成对象 (`obj_gen`)**: 由 Taichi 管理的网格。它包含形成 Voronoi 单元的采样折线。

## 2. 技术规格

### 拓扑引擎 (Python / Mathutils)
插件不使用标准的 Fortune 算法，而是利用 Blender 高性能的 `mathutils.geometry.delaunay_2d_cdt`：
1. **填充边界**: 为了确保所有用户定义的种子都能生成封闭的 Voronoi 多边形，脚本会自动在种子列表中添加 4 个遥远的边界角点。
2. **Delaunay 对偶**: 它执行约束 Delaunay 三角剖分，并通过计算所得三角形的 **外心 (circumcenters)** 来提取对偶 Voronoi 顶点。
3. **径向排序**: 围绕每个种子的外心按逆时针 (CCW) 排序，以形成一致的多边形回路。

### 几何引擎 (Python)
- **边缘缩进 (Edge Retraction)**: 实现并行边缘偏移。单元的每条边都向种子方向向内推进。
- **塌陷处理**: 脚本在缩进过程中监控边缘交点。如果边缘塌陷（交点反转），则将其丢弃以维持有效的拓扑。
- **最小边过滤器**: 在 `CUBIC` 模式下，短于阈值的边将被桥接，从而创造出更平滑的有机形状。

### 采样核 (Taichi)
高性能 Taichi 核处理单元边缘的并行采样。它将每个分段视为 **三次贝塞尔 (Cubic Bezier)** 曲线：
- **线性模式 (Linear)**: 端点和控制点共线，产生直的几何边缘。
- **二次模式 (Quadratic)**: 从边缘中心向角点弯曲，使用 Voronoi 顶点作为单个控制点。
- **三次模式 (Cubic)**: 使用独立的角控制点桥接多个分段，创造出平滑、流动的单元边界。

## 3. 视觉与几何节点

插件以编程方式生成名为 `VoronoiLab_Viz` 的几何节点组：
- **Mesh to Curve**: 将采样后的折线转换为曲线。
- **Curve to Mesh**: 使用圆形轮廓将曲线扫掠成 3D 管状。
- **动态样式**: 倒角半径和分辨率直接从 Taichi 面板控制。

## 4. 数据接口

**生成对象** 暴露以下属性，供几何节点或着色器使用：

| 属性 | 域 (Domain) | 类型 | 描述 |
| :--- | :--- | :--- | :--- |
| `cell_index` | 点 (Point) | `INT` | 该顶点所属的源种子索引。 |

## 5. UI/UX 工作流

1. **选择**: 选择一个 **参考对象**（XY 平面上的顶点）。
2. **初始化**: 单击 **"Initialize Voronoi"**。如果未提供参考，将创建一个默认网格。
3. **调整间距**: 使用 **Spacing** 滑块控制单元之间的间隙。
4. **选择形状**: 在 **Edges**、**Quadratic** 和 **Cubic** 之间切换以获得不同的美学风格。
5. **实时交互**: 在编辑模式下移动参考顶点，实时查看 Voronoi 图更新。
