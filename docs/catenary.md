# 悬链线仿真 (参考对象模式)

此模块实现了一种解析悬链线仿真，为参考网格对象的每条边生成悬链线曲线。

## 1. 架构模式: 参考对象 (Reference Object)

仿真基于 **源-目标 (Source-to-Target)** 关系运行：

- **参考对象 (`obj_ref`)**: 用户定义的网格。该网格的每条边定义了悬链线的两个锚点 ($P_1, P_2$)。
- **生成对象 (`obj_gen`)**: 由 Taichi 管理的网格。它包含所有生成的悬链线的连接顶点和边。

## 2. 技术规格

### 数据映射
- **输入**: `obj_ref` 的所有边顶点坐标被传递给 Taichi。
- **计算**: Taichi 核并行处理所有边，为每条边求解悬链线方程。
- **输出**:
    - **顶点数**: $N_{edges} \times 分辨率$。
    - **边数**: $N_{edges} \times (分辨率 - 1)$。

### 仿真参数
- **松弛度/长度 (Slack/Length)**: 定义每条边电缆长度的两种模式：
    - **松弛模式 (Slack Mode)**: 原始边长的倍数（例如 $1.2\times$）。
    - **相加模式 (Add Mode)**: 在原始边长基础上增加的固定距离（例如 $+0.5$ 单位）。
- **Newton-Raphson 求解器**: 仿真求解方程 $\frac{\sinh(w)}{w} = r$（其中 $r$ 是弧长与水平跨度的比率）以找到悬链线参数。
    - **并行执行**: 每条边在 Taichi 核中独立求解。
    - **迭代限制**: 限制为 25 次迭代（在 UI 中显示为 "Solver Steps"），以确保实时性能。
- **分辨率 (Resolution)**: 每条悬链线曲线的分段数。
- **采样模式 (Sampling Mode)**: 
    - `UNIFORM` (均匀): 沿弧长均匀间距。
    - `ADAPTIVE` (自适应): 在高曲率区域增加顶点密度。此模式使用 **空间权重 (Spatial Weighting)** 策略：
        - **混合逻辑**: 在均匀采样 ($s_u$) 和基于曲率的采样 ($s_a$) 之间进行插值。
        - **权重函数**: $W(t) = \sin(\pi t)$，确保自适应效果在曲线中心最强，向锚点逐渐减弱。
        - **强度**: 缩放局部权重的用户定义参数。

## 3. 视觉与几何节点

插件在 **生成对象** 上以编程方式生成名为 `Catenary_Viz` 的几何节点组：

- **曲线转换**: 网格边转换为具有自动句柄的贝塞尔曲线，以实现平滑插值。
- **倒角 (Beveling)**: 使用 `Curve to Mesh` 节点和 `Curve Circle` 轮廓提供厚度。
- **动态更新**: Taichi 面板中的 "Bevel Radius" 和 "Bevel Resolution" 更改将直接推送到节点组的参数中。

## 4. 数据接口

**生成对象** 暴露以下属性，供几何节点或着色器使用。脚本自动在几何节点树中创建“悬浮”的命名属性节点，以便轻松访问。

| 属性 | 域 (Domain) | 类型 | 描述 |
| :--- | :--- | :--- | :--- |
| `tension` | 点 (Point) | `FLOAT` | 归一化张力（最低点为 0.0，锚点为 1.0）。 |
| `edge_index` | 点 (Point) | `INT` | 该顶点所属的源边索引。 |

## 5. 实时同步

仿真使用高性能同步策略：
- **对象模式 (`sync_mesh_object`)**: 使用 NumPy 和 `foreach_set` 进行快速坐标和属性更新。
- **编辑模式 (`sync_mesh_edit`)**: 如果生成对象处于编辑模式，脚本将切换到 **外科手术式 BMesh 路径 (Surgical BMesh Path)**，允许用户在仿真更新顶点时与其进行交互。
- **依赖跟踪**: `catenary_handler` 监控参考对象的任何更改（变换、几何编辑），并通过 Blender 依赖图 (Depsgraph) 触发重新求解。

## 6. 默认参考对象

如果在用户单击 **"Initialize Catenary"** 时未指定参考对象，系统会自动生成一个默认对象：

- **拓扑**: 5 个顶点，4 条边 —— 沿 X 轴形成水平折线。
- **间距**: 顶点放置在 $x = -2, -1, 0, 1, 2$，均匀间距为 1.0 单位。
- **高度**: 所有顶点放置在 $z = 3.0$（地面平面上方）。
- **命名**: 对象命名为 `Catenary_Ref`。
- 创建后，它将自动分配为 `obj_ref`，并正常进行初始化。

## 7. UI/UX 工作流

1. **选择**: 用户选择一个 **参考对象**（可选 —— 如果省略将生成默认对象）。
2. **初始化**: 用户单击 **"Initialize Catenary"**。创建并链接 **生成对象**。
3. **参考可见性**: UI 在参考对象选择器旁边提供了一个 **Toggle Reference Wire** 按钮。这允许在 `WIRE` (线框) 和 `TEXTURED` (纹理) 显示模式之间快速切换，以便在编辑参考锚点时更容易看到生成的悬链线。
4. **实时交互**: 在编辑模式或对象模式下移动参考对象的顶点会触发生成对象的实时更新。
5. **选择辅助**: 面板中提供了“参考”和“生成”对象的快速选择按钮，以实现快速工作流。
6. **技术信息**: 面板显示 **Solver Steps**（用于性能监控）和 **Source Edges** 计数。后者对于在几何节点或着色器中归一化 `edge_index` 属性非常有用。
