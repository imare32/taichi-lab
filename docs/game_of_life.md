# 生命游戏仿真 (参考对象模式)

此模块在任意 3D 网格的表面实现康威生命游戏 (Conway's Game of Life)。它利用 Taichi 进行并行逻辑计算和状态插值，实现平滑的动态视觉效果。

## 1. 架构模式: 参考对象 (Reference Object)

仿真在 **现有几何拓扑** 上运行：

- **参考对象 (`obj_ref`)**: 用户提供的网格。仿真的计算单元是网格的 **面 (Face)**。
- **状态存储**: 仿真的生存/死亡状态存储在网格面的自定义属性中。

## 2. 技术规格

### 拓扑引擎 (Moore 邻域)
脚本在初始化时提取网格的流形拓扑 (`extract_mesh_topology`)：
- **邻域定义**: 采用摩尔邻域 (Moore neighborhood) 逻辑，即共享至少一个顶点的所有面都被视为邻居。
- **并行映射**: 拓扑结构被转换为 Taichi 可读的邻接矩阵和计数数组，最多支持 12 个邻居。

### 仿真核 (Taichi)
- **并行进化 (`compute_next_generation_kernel`)**: 每代逻辑完全在 GPU 上并行运行。遵循康威标准规则：
    - **存活**: 存活单元若有 2 或 3 个活邻居，则继续存活。
    - **繁衍**: 死亡单元若恰好有 3 个活邻居，则变为存活。
    - **孤独/拥挤**: 其他情况单元死亡。
- **平滑插值 (`interpolate_states_kernel`)**: 实现代际之间的状态转换。支持 **Linear**、**Smoothstep**、**Ease-In** 和 **Ease-Out** 四种插值模式，确保视觉上的生长/衰减效果平滑自然。

## 3. 视觉与几何节点

仿真结果通常与着色器或几何节点结合：
- **着色器驱动**: 使用 `Named Attribute` 节点读取 `alive` 属性，将其作为混合因子来控制自发光或混合两种材质。
- **几何节点缩放**: 使用 `alive` 属性控制面上实例的缩放，创造出动态起伏的效果。

## 4. 数据接口

**参考对象** 的面域暴露以下属性：

| 属性 | 域 (Domain) | 类型 | 描述 |
| :--- | :--- | :--- | :--- |
| `alive` | 面 (Face) | `FLOAT` | 归一化的生命状态。1.0 表示完全存活，0.0 表示死亡，中间值表示插值过程中的过渡态。 |

## 5. 实时同步

- **帧处理器 (Frame Handler)**: 使用 `bpy.app.handlers` 挂载到帧更改事件。
- **动态更新**: 
    - **对象模式 (`sync_mesh_object`)**: 高速更新面属性。
    - **编辑模式 (`sync_mesh_edit`)**: 允许在编辑模式下实时观察生命游戏的演化过程。

## 6. 默认参考对象

如果未指定参考对象，系统将自动生成一个 **圆环面 (Torus)** 作为默认仿真场域：
- **规格**: 大半径 1.0，小半径 0.25。
- **分段**: 48x12 面，提供循环闭合的拓扑结构。

## 7. UI/UX 工作流

1. **选择场域**: 选择一个四边形或三角形网格作为仿真参考。
2. **初始化**: 单击 **"Initialize Game of Life"**。系统将随机初始化种群。
3. **控制节奏**: 
    - **Frames / Gen**: 控制每一代持续的帧数。
    - **Transition Frames**: 控制状态插值（动画过程）所占的帧数。
4. **随机化**: 通过调整 **Seed** 和 **Density** 并重新初始化来改变初始种群分布。
5. **播放**: 播放 Blender 时间轴，观察生命在 3D 表面上的进化。
