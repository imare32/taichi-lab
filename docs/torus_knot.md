# 环面结仿真 (参数化模式)

此模块实现了一个高度可定制的参数化环面结生成器，由 Taichi 加速，具有自适应分辨率和复杂的数学修改器。

## 1. 架构模式: 参数化生成

与基于参考的脚本不同，环面结仿基于 **纯参数化 (Purely Parametric)** 运行：

- **数学引擎**: 使用标准的环面结方程，由整数 $p$ 和 $q$ 参数化。
- **生成对象 (`obj_gen`)**: 一个名为 `TorusKnot_Generated` 的独立网格，完全由仿真管理。

## 2. 技术规格

### 数学修改器
脚本通过几个高级控件扩展了基础环面结公式：
- **p & q**: 结绕环面的两个轴缠绕的次数。
- **公转与自转倍增器 (Revolution & Spin Multipliers)**: 缩放公转和自转角速度的整数倍增器，允许创建复杂的、自相交的“超级结”。
- **公转与自转相位 (Revolution & Spin Phases)**: 偏移结线程起始位置的浮点偏移量。
- **多重链路 (Multiple Links)**: 自动检测所选的 $p$ 和 $q$ 是否会导致多个独立组件（使用 $gcd(p, q)$），并将它们生成为同一网格中的不同圆形回路。

### 自适应分辨率
分辨率可以手动管理或自动管理：
- **计算**: 启用 `Adaptive Resolution` 时，脚本使用半径 ($R, r$) 和缠绕数 ($p, q$) 计算结的近似弧长。
- **缩放**: 然后缩放顶点数以保持一致的线性密度，确保即使在结的复杂度增加时也能获得平滑的曲线。

## 3. 视觉与几何节点

插件以编程方式生成名为 `TorusKnot_Viz` 的几何节点组：

- **贝塞尔平滑**: 将 Taichi 生成的离散折线转换为具有 **自动句柄** 的平滑贝塞尔样条线。
- **管状扫掠 (Tube Sweeping)**: 使用 `Curve to Mesh` 节点和 `Curve Circle` 轮廓。
- **倒角控制 (Bevel Control)**: 厚度和轮廓分辨率直接在 Taichi 面板中公开，用于实时样式设置。

## 4. 数据接口

**生成对象** 提供了类似 UV 的映射坐标，用于着色器中：

| 属性 | 域 (Domain) | 类型 | 描述 |
| :--- | :--- | :--- | :--- |
| `u_map` | 点 (Point) | `FLOAT` | 沿公转轴的归一化映射 ($[0.0, 1.0]$)。 |
| `v_map` | 点 (Point) | `FLOAT` | 沿自转轴的归一化映射 ($[0.0, 1.0]$)。 |

## 5. 实时同步

- **状态管理**: 使用 `is_dirty` 模式最小化冗余计算。
- **混合同步**: 
    - **对象模式 (`sync_mesh_object`)**: 用于快速视口更新的高速 `foreach_set` 同步。
    - **编辑模式 (`sync_mesh_edit`)**: **外科手术式 BMesh 路径 (Surgical BMesh Path)**，仅在必要时重建拓扑，允许对结的形状进行无缝的交互式编辑。

## 6. UI/UX 工作流

1. **初始化**: 单击 **"Initialize Torus Knot"** 创建生成器和目标网格。
2. **雕刻结**: 调整 $p, q$、半径和高度来定义基本形状。
3. **高级微调**: 使用倍增器和相位来创建复杂的模式。
4. **视觉完善**: 切换 `Adaptive Resolution` 以实现自动质量控制，并调整 `Bevel Radius` 以改变厚度。
5. **选择**: 使用 "Select Generated" 辅助按钮快速跳转到结对象，以便进行进一步的 Blender 操作（如材质分配）。
